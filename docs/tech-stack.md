# Billate — Tech Stack (MVP)

## Language & Build
- **Kotlin**
- **Gradle (Kotlin DSL)**

## UI
- **Jetpack Compose**
- **Material 3**
- **Navigation Compose**
- **Accompanist** (optional for permissions and system UI)

## Architecture
- **MVVM**
- **StateFlow + Coroutines**
- **Unidirectional Data Flow (UDF)**

## Dependency Injection
- **Hilt**

## Data Storage
- **Room** (local database)

## Networking / AI
- **Google AI Android SDK** (Gemini)
- **Kotlinx Serialization** (JSON, for strict response parsing)

## Image Input
- **CameraX** (camera capture)
- **Android Photo Picker** (gallery selection)

## Utilities
- **Coil** (image loading in Compose)
- **Timber** (logging)

## Testing (optional for MVP)
- **JUnit**
- **Turbine** (Flow testing)
- **MockK** (unit tests)

## Tooling
- **Android Studio**
- **Detekt / ktlint** (style checks, optional)
